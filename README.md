# 📱 Аксики Сетики

Android application for Arizona RP players, providing convenient mobile access to the "Аксики Сетики" accessory configurator.

> Lightweight Android client with offline caching, Google Play distribution, Unity Ads monetization, and 5000+ real users.

---

## 🚀 Project Overview

The application was developed as a lightweight Android wrapper around an existing web platform, focusing on:

- Mobile accessibility
- Offline-first experience
- Google Play distribution
- Advertisement monetization
- User acquisition and retention

Unlike a typical portfolio project, the application was released to real users through Google Play, promoted through community channels, monetized, and maintained in production for over a year.
